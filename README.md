This repository contains my Basic Computer Proficiency Skills (BCPS) lab assignments. It includes practical work related to Command Line Interface, LibreOffice Writer, Calc, Impress, and basic problem-solving.

## Lab Assignments

### Lab 1: Basic File Management
Create folders and files using CLI commands such as mkdir, cd, dir/ls, and rmdir and perform basic file management operations.

### Lab 2: File and Folder Management
Practice creating, navigating, and managing files and folders using command-line commands.

### Lab 3: System Configuration and Networking
Demonstrate basic system configuration and networking commands using the Command Line Interface.

### Lab 4: Document Formatting
Create and format a professional document using LibreOffice Writer with text formatting, tables, headers, footers, and page numbering.

### Lab 5: Mail Merge
Create personalized invitation letters using the Mail Merge feature in LibreOffice Writer.

### Lab 6: Student Marksheet
Prepare a student marksheet in LibreOffice Calc using formulas and functions such as SUM, AVERAGE, MAX, and MIN.

### Lab 7: Attendance and Salary Calculation
Create spreadsheets for attendance tracking and salary calculation using LibreOffice Calc.

### Lab 8: Inventory Management
Create a spreadsheet for inventory management using LibreOffice Calc.

### Lab 9: Educational Presentation
Develop an educational presentation in LibreOffice Impress using themes, slide transitions, animations, and multimedia objects.

### Lab 10: Presentation Design
Create and format presentation slides using LibreOffice Impress.
